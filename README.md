# Metal Mod

This is a fabric mod that introduces a brand new **Metal** based voxel rendering engine to **Minecraft java** in order to both replace the default OpenGL renderer and bring performance improvements to **MacOS devices ONLY**.

### Why?
- Minecraft performance is pretty shit on MacOS and Apple makes it hard as hell to do anything related to Metal so not many people have tried, except moi
- Most modern shaders cannot run on MacOS Minecraft due to Apple deprecating OpenGL 4.6 support
- Moar fps for the light side
